# Privacy Policy

_Last updated: 2026-11-15_

This page covers the Google OAuth application owned by the maintainer of this repository. The application is a personal tool used only by its owner, for example to back up personal files to Google Drive.

- **Who uses it:** only the owner. It is not offered to the public.
- **What it accesses:** only the owner's own Google account data, such as Google Drive files, and only as far as personal backups and automation need.
- **What it collects:** nothing. The application does not collect, sell, share or transfer user data to any third party.
- **Where data is stored:** data stays in the owner's Google account and on the owner's own computers.
- **Revoking access:** access can be revoked at any time at <https://myaccount.google.com/permissions>.

Questions can be raised through this repository's GitHub Issues.

---

## 隐私政策（中文）

本页说明本仓库维护者名下的 Google OAuth 应用。该应用是个人工具，只供所有者本人使用，例如把个人文件备份到 Google 云端硬盘。

- **使用者**：只有所有者本人，不对外提供。
- **访问范围**：只访问所有者本人 Google 账号中的数据（如云端硬盘文件），仅限个人备份与自动化需要的范围。
- **数据收集**：不收集、不出售、不共享、不向任何第三方传输用户数据。
- **数据存放**：数据只保存在所有者本人的 Google 账号和本人电脑中。
- **撤销授权**：可随时在 <https://myaccount.google.com/permissions> 撤销。

如有疑问，请通过本仓库的 GitHub Issues 联系。
